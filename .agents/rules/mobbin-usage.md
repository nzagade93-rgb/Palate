# Mobbin Design Reference Integration

Use the Mobbin MCP tools (`search_screens`, `search_flows`, `search_sections`) when looking for:
- Real-world UI/UX patterns and design inspirations from top apps (e.g. food delivery, loyalty apps, restaurant ordering, checkout flows).
- Real production app screens from Mobbin's index of 600,000+ screens.
- Multi-step customer journeys (onboarding, check-in flows, redemption passes).

When searching Mobbin:
1. `search_screens`: Search specific UI screens by keyword, app category, or UI element.
2. `search_flows`: Search complete user flows (e.g. "food check in", "loyalty voucher", "restaurant menu").
3. `search_sections`: Find specific page sections (pricing, hero, navigation, modals).
